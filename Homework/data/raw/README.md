# 原始数据说明

## 文件

`public.csv` — 门店层面的电话调查数据，410 行 × 46 列，UTF-8 编码，含表头。

> **这个文件不在 Git 仓库里。** 本仓库是公开仓库，而原始调查数据受课程数据使用条款
> 约束（不得公开分发），因此已被 `.gitignore` 排除。要复现结果，请按下文"如何取得数据"
> 一节把 `public.csv` 放回本目录，路径必须恰好是 `data/raw/public.csv`。

## 来源

该数据是 Card 与 Krueger (1994) 为研究新泽西州 1992 年最低工资上调而自行收集的调查数据，
由本课程（ECON6067B）以 `01_DID.zip` 的形式分发。数据收集的完整描述见论文：

> Card, D., & Krueger, A. B. (1994). Minimum Wages and Employment: A Case Study of the
> Fast-Food Industry in New Jersey and Pennsylvania. *American Economic Review*, 84(4),
> 772–793.

调查分两轮进行：

| 轮次 | 时间 | 新泽西最低工资 |
| --- | --- | --- |
| 第 1 轮 | 1992 年 2–3 月 | 4.25 美元（改革前） |
| 第 2 轮 | 1992 年 11–12 月 | 5.05 美元（改革后） |

调查对象为新泽西全部 3 个地区与宾州东部 2 个地区的 Burger King、KFC、Roy Rogers、
Wendy's 四个连锁品牌的全部门店。

## 如何取得数据

`public.csv` 不随本仓库分发。要复现全部结果：

1. 从课程平台（ECON6067B）下载 `01_DID.zip`；
2. 解压，把其中的 `public.csv` 复制到本目录，路径为 `data/raw/public.csv`；
3. 运行 `python3 run_all.py`。`run_all.py` 会先检查该文件是否存在，缺失时明确报错退出，
   不会静默生成空结果。

审核人员应能通过课程渠道取得同一份文件。用同一份数据从零运行，`results/` 中的全部
输出应当与仓库中已提交的版本逐字节一致。

## 使用限制

**该数据仅可在本课程的项目范围内使用，不得公开分发。** 数据中虽已去掉门店名称与地址，
但仍是作者收集的受限调查数据。

本仓库因此采用如下安排：

- **原始数据 `data/raw/public.csv` 已被 `.gitignore` 排除，不进入版本控制。** 公开仓库
  中不含这份文件。
- **`data/processed/analysis_sample.csv` 同样被排除。** 它是 410 行的门店级分析样本，
  逐店可读且保留了原始文件的全部列——公开它等同于公开原始数据。该文件由
  `src/prepare_data.py` 自动重建，无需分发。
- 论文原文 `docs/njmin-aer.pdf` 同样受版权保护，也未跟踪；仓库中只保留完整文献引用。
- **可以安全公开的是汇总结果：** 代码（`src/`）、本文件（字段说明）、
  `data/processed/descriptives.csv`、以及 `results/` 中的全部表格与图。它们都不含逐店记录。

## 字段说明

### 标识与分组

| 字段 | 含义 |
| --- | --- |
| `SHEET` | 门店编号（数据行标识） |
| `CHAIN` | 连锁品牌：1 = Burger King，2 = KFC，3 = Roy Rogers，4 = Wendy's |
| `CO_OWNED` | 1 = 公司直营店，0 = 加盟店 |
| `STATE` | 1 = 新泽西（处理组），0 = 宾夕法尼亚（对照组） |
| `NORTHJ` / `CENTRALJ` / `SOUTHJ` | 新泽西三个地区的哑变量，各自 1/0 |
| `PA1` | 1 = 宾州费城东北郊 |
| `PA2` | 1 = 宾州伊斯特顿地区 |
| `SHORE` | 1 = 位于海滨地区 |

原始数据中是**五个互相独立的地区哑变量**，每个门店恰好有一个取 1。
代码里的 `region` 是一个**派生列**（见 `src/prepare_data.py`），由这五个哑变量合并而成，
取值 `NORTHJ` / `CENTRALJ` / `SOUTHJ` / `PA1` / `PA2`，仅用于生成地区控制变量。
本节未列出的其余原始列（`NCALLS`、`INCTIME`、`FIRSTINC`、`BONUS`、`PCTAFF`、
`MEALS`、`OPEN`、`NREGS`、`TYPE2`、`DATE2` 等）是调查的过程变量，本分析未使用。

### 第 1 轮（1992 年 2–3 月，改革前）

| 字段 | 含义 |
| --- | --- |
| `EMPFT` | 全职员工数 |
| `EMPPT` | 兼职员工数 |
| `NMGRS` | 经理数 |
| `WAGE_ST` | 起薪（美元/小时） |
| `HRSOPEN` | 每日营业小时数 |
| `PSODA` | 中杯汽水价格（美元） |
| `PFRY` | 小份薯条价格（美元） |
| `PENTREE` | 主菜价格（美元） |

### 第 2 轮（1992 年 11–12 月，改革后）

同名字段加上后缀 `2`：`EMPFT2`、`EMPPT2`、`NMGRS2`、`WAGE_ST2`、`HRSOPEN2`、
`PSODA2`、`PFRY2`、`PENTREE2`。

### 门店状态

| 字段 | 含义 | 门店数 |
| --- | --- | --- |
| `STATUS2` = 0 | 拒访（无第 2 轮数据） | 1 |
| `STATUS2` = 1 | 正常经营 | 399 |
| `STATUS2` = 2 | 重新装修 | 2 |
| `STATUS2` = 3 | 永久关闭 | 6 |
| `STATUS2` = 4 | 改址/道路施工 | 1 |
| `STATUS2` = 5 | 商场火灾后停业 | 1 |

就业处理规则：

- `== 3`（永久关闭，6 家）：第 2 轮就业记为 **0**。
- `∈ {2, 4, 5}`（临时关闭，4 家）：第 2 轮就业记为 **缺失**。
- `== 0`（拒访，1 家）：第 2 轮数据整行为空，自然被排除，无需特殊规则。

前两条与论文表 4 注释的"6 家永久关闭记为 0、4 家临时关闭剔除"逐一对应，是复现论文
样本量（357 家门店）的关键。详见 `../../report/empirical_report.md` 第 2.2 节与
`../../src/prepare_data.py`。

## 缺失值

数据中的缺失以空单元格表示，由 `pandas.read_csv` 读作 `NaN`。分析代码不做插补：
每个回归按其变量的实际可得性确定样本量。
